# 推理框架

推理框架（Inference Framework）是指用于加载、优化和执行已训练好的机器学习或深度学习模型，以对新数据进行预测或决策的软件系统。它通常不涉及模型的训练过程，而是专注于高效、低延迟、高吞吐地运行模型，尤其是在生产环境、边缘设备或云端服务中。

一个优秀的推理框架需要具备以下特性：

- **高性能**：支持硬件加速（如CPU、GPU、TPU、NPU等）
- **低延迟与高吞吐**：适用于实时应用
- **跨平台支持**：可在服务器、移动端、嵌入式设备上运行
- **模型兼容性**：支持主流训练框架导出的模型格式
- **优化能力**：如量化、剪枝、算子融合、内存优化等

---

### 一、通用/主流的推理框架（跨领域）

这些框架支持多种模型类型，广泛应用于计算机视觉、自然语言处理、语音识别等多个领域。

|框架|开发者|特点|
|---|---|---|
|**TensorRT**|NVIDIA|针对NVIDIA GPU高度优化，支持FP16/INT8量化，常用于部署CNN、Transformer类模型|
|**ONNX Runtime**|Microsoft|支持ONNX格式模型，跨平台（CPU/GPU/DirectML/NPU），支持多后端（CUDA, TensorRT, OpenVINO等）|
|**OpenVINO**|Intel|针对Intel CPU/GPU/VPU优化，擅长在x86边缘设备上部署CV模型|
|**TVM**|Apache / TVM Community|开源编译器框架，可将模型编译为针对不同硬件（包括ARM、FPGA、ASIC）的高效代码|
|**TensorFlow Lite**|Google|轻量级，专为移动和嵌入式设备设计，支持Android/iOS|
|**PyTorch Mobile / TorchScript / TorchServe**|Meta (Facebook)|PyTorch原生支持移动端和服务器端推理|
|**NCNN**|Tencent|无第三方依赖，专为手机端优化的高性能推理框架（C++），适合Android/iOS|
|**MNN**|Alibaba|阿里开源的轻量级推理引擎，跨平台，性能优秀，广泛用于移动端App|
|**Paddle Inference**|Baidu PaddlePaddle|飞桨配套推理库，支持服务器、移动端、边缘芯片，中文场景优化好|
|**Core ML**|Apple|苹果生态专用，集成于iOS/macOS系统，支持神经网络、树模型等|
|**Snapdragon Neural Processing Engine (SNPE)**|Qualcomm|专为骁龙芯片优化，支持Caffe、TensorFlow、ONNX等模型，在安卓手机上高效运行|

### 二、按领域划分的流行模型与对应推理框架

#### 1. **计算机视觉（CV）**

- **典型模型**：
    - CNN系列：ResNet、EfficientNet、MobileNet、YOLO（v5/v8）、RetinaNet
    - Transformer：ViT、Swin Transformer、DETR
- **常用推理框架**：
    - TensorRT（NVIDIA GPU部署首选）
    - OpenVINO（Intel CPU边缘设备）
    - NCNN / MNN / TFLite（移动端人脸识别、摄像头分析）
    - ONNX Runtime（跨平台部署统一接口）
    - SNPE（高通平台手机AI相机功能）

#### 2. **自然语言处理（NLP）**

- **典型模型**：
    - BERT、RoBERTa、ALBERT、DistilBERT
    - GPT系列（GPT-2, LLaMA, ChatGLM, Qwen）
    - T5、BART
- **常用推理框架**：
    - **Hugging Face Transformers + ONNX Runtime / TensorRT**（最常见组合）
    - **vLLM**（专为大语言模型设计，支持LLaMA、GPT等，高吞吐）
    - **Text Generation Inference (TGI)** by HuggingFace + Rust/CUDA（生产级LLM服务）
    - **DeepSpeed-Inference**（微软，支持大模型张量并行）
    - **Llama.cpp**（纯C/C++实现，可在Mac/PC/嵌入式设备本地运行LLaMA系列）
    - **GGUF + llama.cpp / KoboldCpp / Whisper.cpp**（量化后的小模型本地运行）

#### 3. **语音识别与合成（ASR/TTS）**

- **典型模型**：
    - ASR：Whisper、DeepSpeech、Conformer
    - TTS：Tacotron、FastSpeech、WaveNet
- **常用推理框架**：
    - **Whisper.cpp**（C++版Whisper，可在无GPU环境下运行）
    - **ONNX Runtime**（部署PyTorch/TensorFlow转ONNX的语音模型）
    - **TensorRT**（NVIDIA Jetson上部署实时语音识别）
    - **Kaldi + nnet3/xvector**（传统语音识别系统仍在工业界使用）
    - **Mozilla DeepSpeech**（基于TensorFlow Lite部署）

#### 4. **推荐系统**

- **典型模型**：
    - DLRM、Wide & Deep、DeepFM、YouTube DNN
- **常用推理框架**：
    - **TensorFlow Serving**（Google推荐系统常用）
    - **TorchServe**（PyTorch模型服务化）
    - **NVIDIA Merlin HugeCTR Inference**（专为大规模推荐模型优化，支持GPU加速）
    - **ONNX Runtime**（跨平台统一部署）
    - **Faiss + 自定义推理逻辑**（用于近似最近邻检索部分）

#### 5. **强化学习（RL）**

- **典型模型**：
    - DQN、PPO、A3C、DDPG
- **常用推理框架**：
    - **Ray RLlib**（支持训练后导出策略网络进行推理）
    - **TensorFlow Lite / TorchScript**（嵌入式设备上的轻量级推理）
    - **自定义C++推理引擎**（游戏AI、机器人控制中常见）

#### 6. **图神经网络（GNN）**

- **典型模型**：
    - GCN、GAT、GraphSAGE
- **常用推理框架**：
    - **PyTorch Geometric + TorchScript**
    - **DGL (Deep Graph Library) + DGL Serving**
    - **TVM**（对GNN算子进行定制化优化）
    - **ONNX Runtime**（部分GNN可转换为ONNX）

#### 7. **时间序列预测**

- **典型模型**：
    - LSTM、GRU、Temporal Fusion Transformer (TFT)、N-BEATS
- **常用推理框架**：
    - **ONNX Runtime**（金融、电力等行业常用）
    - **TensorFlow Lite**（边缘设备预测）
    - **TVM**（特定硬件加速）
    - **Custom C++/Python wrappers**

#### 8. **医学影像分析**

- **典型模型**：
    - 3D U-Net、nnUNet、Vision Transformers
- **常用推理框架**：
    - **NVIDIA Clara / MONAI Deploy**（医疗专用AI平台）
    - **TensorRT**（医院GPU服务器部署）
    - **OpenVINO**（用于CT/MRI设备中的边缘推理）

#### 9. **自动驾驶**

- **典型模型**：
    - BEVFormer、CenterPoint、YOLOP（多任务）
- **常用推理框架**：
    - **NVIDIA DRIVE Platform + TensorRT**
    - **Apollo Auto + Custom Inference Engine**
    - **TVM**（适配多种车载芯片）
    - **QNN (Qualcomm Neural Network SDK)**（用于车内信息娱乐系统）

#### 10. **大模型（LLM）专用推理框架**

随着大语言模型兴起，出现了专门针对其特点优化的推理系统：

|框架|特点|
|---|---|
|**vLLM**|使用PagedAttention技术，显著提升吞吐量，支持HuggingFace模型|
|**Text Generation Inference (TGI)**|HuggingFace推出，支持连续批处理、FlashAttention、量化|
|**Llama.cpp**|纯C/C++，无需依赖，支持GGUF量化格式，可在笔记本甚至树莓派运行|
|**ExLlama / ExLlamaV2**|高效运行LLaMA类模型，支持4-bit量化|
|**DeepSpeed-MII**|微软，基于DeepSpeed的大模型推理部署工具|
|**FlexGen**|支持超大模型的内存管理与分片推理|
|**Orca**|支持分布式推理，适合私有化部署大模型|

### 三、总结：选择推理框架的关键因素

|因素|推荐框架示例|
|---|---|
|**追求极致性能（NVIDIA GPU）**|TensorRT、TGI、vLLM|
|**Intel CPU边缘设备**|OpenVINO|
|**移动端（Android/iOS）**|NCNN、MNN、TFLite、Core ML|
|**跨平台统一部署**|ONNX Runtime|
|**本地运行大模型（无GPU）**|Llama.cpp、KoboldCpp|
|**生产级服务部署**|TorchServe、TF Serving、TGI、vLLM|
|**定制硬件（FPGA/ASIC）**|TVM、Apache Arrow with Gandiva|
|**轻量级嵌入式设备**|TensorFlow Lite Micro、CMSIS-NN|

### 补充说明（截至2025年趋势）：

- **ONNX** 成为事实上的中间表示标准，许多框架都支持导出ONNX再用ONNX Runtime推理。
- **量化技术普及**：INT8、FP16、4-bit量化成为标配，大幅降低资源消耗。
- **模型即服务（MaaS）** 兴起，推理框架更多作为后端支撑云API。
- **国产芯片适配增强**：寒武纪（MagicMind）、华为昇腾（CANN）、地平线（Horizon BPU）等均有自研推理栈。
