### 步骤总结

可以把整个流程压缩成一套固定工作流。你的最终架构是：

```text
Obsidian
   │
   ▼
knowledge-notes             # 笔记源仓库，唯一内容源
   │
   │ 手动 rsync
   ▼
UsuGarden/content           # Quartz 网站内容
   │
   ▼
UsuGarden                   # Quartz 5 网站仓库
   │ git push v5
   ▼
GitHub Actions
   │
   ▼
GitHub Pages
```

核心原则：**平时只在 `knowledge-notes` 写笔记；`UsuGarden/content` 只是它的发布副本。**

## 一、第一次部署

假设：

```bash
~/knowledge-notes    # 已有 Obsidian 知识库
~/UsuGarden          # 新建 Quartz 网站
```

### 1. 创建 Quartz 5

```bash
cd ~

git clone https://github.com/jackyzha0/quartz.git UsuGarden
cd UsuGarden

npm install
npx quartz create
```

初始化时选择：

```text
Template:
Obsidian

Content:
Empty Quartz

Base URL:
JR-Wesley.github.io/UsuGarden
```

然后：

```bash
npx quartz plugin install --from-config
```

### 2. 创建网站首页

确保存在：

```bash
vim ~/UsuGarden/content/index.md
```

例如：

```markdown
---
title: UsuGarden
---

# UsuGarden

我的个人知识库。
```

这个文件作为网站 `/` 首页。

### 3. 第一次同步 Obsidian 笔记

```bash
rsync -av --delete \
  --exclude='.git' \
  --exclude='.obsidian' \
  --exclude='.trash' \
  ~/knowledge-notes/ \
  ~/UsuGarden/content/
```

注意：如果 `index.md` 只存在于 `UsuGarden/content` 而源仓库没有，`--delete` 可能把它删除。

所以更推荐把首页也放进：

```text
knowledge-notes/index.md
```

这样：

```text
knowledge-notes
        ↓ rsync
UsuGarden/content
```

始终完全镜像，不需要特殊处理。

### 4. 本地测试 Quartz

```bash
cd ~/UsuGarden

npx quartz build
```

确认：

```bash
ls public/index.html
```

需要预览：

```bash
npx quartz build --serve
```

如果 Quartz 在远程服务器运行，本地电脑建立 SSH tunnel：

```bash
ssh -L 8080:localhost:8080 user@server
```

然后电脑浏览器打开：

```text
http://localhost:8080
```

### 5. 创建自己的 GitHub 网站仓库

GitHub 创建：

```text
JR-Wesley/UsuGarden
```

然后把 Quartz 的 remote 改成：

```bash
cd ~/UsuGarden

git remote remove origin

git remote add origin git@github.com:JR-Wesley/UsuGarden.git
git remote add upstream https://github.com/jackyzha0/quartz.git
```

因此：

```text
origin    → JR-Wesley/UsuGarden
upstream  → jackyzha0/quartz
```

然后推送：

```bash
git add .
git commit -m "initialize Quartz site"
git push -u origin v5
```

### 6. 创建 GitHub Pages Action

Quartz 自带的：

```text
Build and Test
Deploy v5 Preview
Docker build
...
```

主要是 Quartz 官方项目自己的 workflow，不是你的 Pages workflow。

创建：

```bash
vim .github/workflows/pages.yml
```

内容：

```yaml
name: Deploy Quartz to GitHub Pages

on:
  push:
    branches:
      - v5
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v6
        with:
          fetch-depth: 0

      - name: Setup Node
        uses: actions/setup-node@v6
        with:
          node-version: 24

      - name: Install dependencies
        run: npm ci

      - name: Install Quartz plugins
        run: npx quartz plugin install

      - name: Build Quartz
        run: npx quartz build

      - name: Upload Pages artifact
        uses: actions/upload-pages-artifact@v4
        with:
          path: public

  deploy:
    needs: build
    runs-on: ubuntu-latest

    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}

    steps:
      - name: Deploy
        id: deployment
        uses: actions/deploy-pages@v4
```

提交：

```bash
git add .
git commit -m "add GitHub Pages deployment"
git push origin v5
```

### 7. GitHub 开启 Pages

GitHub：

```text
UsuGarden
→ Settings
→ Pages
→ Build and deployment
→ Source
→ GitHub Actions
```

然后：

```text
Actions
→ Deploy Quartz to GitHub Pages
```

确认：

```text
✓ build
✓ deploy
```

网站就是：

```text
https://JR-Wesley.github.io/UsuGarden/
```

到这里第一次部署完成。

# 二、以后日常更新

第一次配置完成后，实际上只剩下非常简单的流程。

## 1. 正常更新 Obsidian 笔记

你原来的工作流完全不变：

```bash
cd ~/knowledge-notes

git add .
git commit -m "update notes"
git push
```

## 2. 同步到 Quartz

```bash
rsync -av --delete \
  --exclude='.git' \
  --exclude='.obsidian' \
  --exclude='.trash' \
  ~/knowledge-notes/ \
  ~/UsuGarden/content/
```

## 3. 可选：本地检查

普通更新其实可以直接：

```bash
cd ~/UsuGarden
npx quartz build
```

重要修改想看看效果：

```bash
npx quartz build --serve
```

## 4. 发布

```bash
cd ~/UsuGarden

git add content
git commit -m "update site content"
git push origin v5
```

结束。

后面的：

```text
git push
   ↓
GitHub Actions
   ↓
Quartz build
   ↓
public/
   ↓
GitHub Pages
   ↓
网站更新
```

全部自动完成。

# 三、所以以后真正需要记住的命令

实际上就是：

```bash
# ===== 更新源笔记 =====

cd ~/knowledge-notes

git add .
git commit -m "update notes"
git push


# ===== 更新网站 =====

rsync -av --delete \
  --exclude='.git' \
  --exclude='.obsidian' \
  --exclude='.trash' \
  ~/knowledge-notes/ \
  ~/UsuGarden/content/

cd ~/UsuGarden

npx quartz build

git add content
git commit -m "update site content"
git push origin v5
```

其中 `npx quartz build` 甚至是可选的，因为 GitHub Actions 本身会重新 build。保留它的意义主要是**发布前发现 Markdown / Quartz 构建错误**。

因此最精简版本实际上只有：

```bash
# 笔记
cd ~/knowledge-notes
git add .
git commit -m "update notes"
git push

# 网站
rsync -av --delete \
  --exclude='.git' \
  --exclude='.obsidian' \
  ~/knowledge-notes/ ~/UsuGarden/content/

cd ~/UsuGarden
git add content
git commit -m "update site"
git push origin v5
```

以后如果你觉得这几个命令仍然麻烦，下一步只需要把“网站”这部分封装成一个 `publish-notes` shell function 或 `publish.sh`。那你的日常操作就能进一步缩成：

```bash
cd ~/knowledge-notes
git add .
git commit -m "update notes"
git push

publish-notes
```

这已经足够作为长期稳定的 **Obsidian → Git → Quartz 5 → GitHub Pages** 工作流。
