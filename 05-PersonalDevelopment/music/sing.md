# 唱歌

mix https://www.youtube.com/watch?v=K2rl_f1KFP4

# Summary

1. 录音是唯一客观镜子；可周更 vlog；每次来工作室用全民录歌就可以了
2. KTV 实战技巧：
    1. 唱歌胸椎反弓，能让肚子顶上去不泄气
    2. 看一个字闭着眼背歌词，感受伴奏的重音去调整自己的节奏
3. 我的舒适区：B2-C4，C5 开始是我的假声（B4 是鼓楼里的『过客』），视唱时候的 4 是最接近说话的发音
4. 若遇到嗓子干、沙哑或高音卡喉，立即停唱，改做轻度“呜呜”滑音 + 多喝温水；声带是肌肉，休息也是训练的一部分。祝练嗓愉快！
5. 唱歌的时候跟着前奏找调很重要。
6. 旋律，可以理解为是另一张简谱，但是是和歌词的简谱有对应的，两者对应起来是和弦。需要用一些重音的点来校准自己的节拍。我不准的是句和句之间的停顿的地方
7. 先哼歌再唱歌。  嗓子和嘴吧分开。唱歌感受稳定气流穿过喉咙。na-na-na 和哼的区别是强迫张口混声
8. [音准](https://liu-gong-zi.com/2+%E7%AC%AC%E4%BA%8C%E5%A4%A7%E8%84%91/1+%E6%A6%82%E5%BF%B5/1+%E7%A4%BE%E4%BC%9A%E4%B8%8E%E6%96%87%E6%98%8E/%E6%96%87%E6%98%8E/%E8%89%BA%E6%9C%AF/%E9%9F%B3%E4%B9%90/%E9%9F%B3%E5%87%86) 相关：鼻腔和头腔共鸣是两条岔路，唱歌上来就用头不要经过鼻子，就不会卡高音了，高音调要有撕开的感觉。往前面穿透前去。到了前额以后，放松再顶一下可以实现 [头腔共鸣](https://liu-gong-zi.com/%E5%A4%B4%E8%85%94%E5%85%B1%E9%B8%A3)。混声。咬字积极 口腔要圆。发力要轻；区分音调和唱名的不同，练听音的时候不是听唱名的吻合度，而是听音调的粗和细
9. 气息控制：通过打 du 解决高音的气息控制，
10. 从 321 下来的时候直接 3 到 2 而不是。3 到 0 到 2
11. 模版：毛不易 李宗盛 薛之谦 李荣浩 陈奕迅 周杰伦

## 技术栈

|技能|练什么|典型练法|自查/纠错|
|---|---|---|---|
|气息支撑|稳压 + 续航|吹纸片、吸管发声、hiss - sigh|录音波形是否“一条线”|
|共鸣位置|胸→口→头 →混声|嗡鸣 (m-n-ng)、sirens|闭嘴哼唱感觉“鼻梁震”|
|音准|纯音/跳音|琴键 - 耳返同步；VocalPitchMonitor|cent 误差图像化|
|节奏|内部节拍器|2-4-8-16 拍手 + 口数|随 drum loop 闭眼点脚|
|装饰音|滑音, 颤音, 倚音|riff & run 拆分 - 拼接；metronome 60→120|用 DAW 波形看连贯性|
|音域拓展|passaggio|lip trills, octave sirens|高音是否放松无挤压|
|舞台表现|眼神 - 肢体|镜前 shadowing；Open-Mic|录像自评表（走位/情感）|
|录音与混音|麦距 + 后期|双轨叠唱, basic EQ-Comp-Reverb|A/B 原声 vs 混音差异|

## 王力宏声乐课程列表

滑音 (huáyīn)：是一种演唱技巧，指的是：声音从一个音高平滑、连续地过渡或连接到另一个音高，中间没有明显的阶梯式跳跃或断开。简单来说，就是像“溜”一样地把声音从一个音滑到另一个音，可以向上滑也可以向下滑。
